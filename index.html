Two ideas to remember

Click each card.

Code optimization

Making the same method run faster or use less memory. Example: using rowSums() instead of apply().

Algorithmic efficiency

Choosing a better method, so the work grows slowly as data grows. Example: binary search instead of checking every item.

Golden rule: first make it correct, then measure, then speed up only the slow part.

SDTM: keep only what you need
Raw demographics often has extra columns.



dm <- raw_dm
dm <- raw_dm[, c("SUBJID", "SEX", "AGE")]

raw_dmThe collected data.

💡 Smaller data means less to carry through later steps. Keep every variable your specification needs.


SDTM: clean text once
Tidy the value one time, then reuse it.



ae$AESEV <- toupper(trimws(ae$RAWSEV))
severe <- ae[toupper(trimws(ae$RAWSEV)) == "SEVERE", ]
ae$AESEV <- toupper(trimws(ae$RAWSEV))
severe <- ae[ae$AESEV == "SEVERE", ]
📖 Explain this code
trimws()Remove extra spaces.
toupper()Make capital letters.
== "SEVERE"Keep severe events.


💡 The second line reuses AESEV instead of cleaning the text again.


ADaM: convert a date once
Save the converted date and reuse it.



adae$ASTDY <- as.Date(adae$AESTDTC) - adae$TRTSDT + 1
adae$ASTMON <- months(as.Date(adae$AESTDTC))
adae$ASTDT <- as.Date(adae$AESTDTC)
adae$ASTDY <- adae$ASTDT - adae$TRTSDT + 1
adae$ASTMON <- months(adae$ASTDT)
📖 Explain this code
as.Date()Turn date text into a real date.
TRTSDTTreatment start date.
months()Name of the month.


💡 Same idea as memoization: work it out once. This day formula is for events on or after treatment start, with complete dates.

Better algorithm: binary search
Find a number in a sorted list. Pick a target, then compare the two methods.






# In R, on a sorted vector x
which(x == target)        # checks every item: O(n)
findInterval(target, x)       # binary search: O(log n)


findInterval returns the position of the last value ≤ target, so confirm x[pos] == target.
💡 For 1,000,000 sorted values, binary search needs at most 20 checks. Joins by USUBJID are a lookup problem too: use match() or a join, not a separate search for each record.
